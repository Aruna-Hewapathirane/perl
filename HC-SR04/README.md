The HC-SR04 is a popular, low-cost ultrasonic distance sensor used to detect objects and measure distances without physical contact. 
It works by using high-frequency sound waves, functioning essentially like a miniature radar or bat sonar.It can measure distances 
ranging from 2 cm to 400 cm (approx. 1 inch to 13 feet) with an accuracy of up to 3 mm.
